Bern Libraries

Every library ships with Bern. Each one has its own page with a full function reference and worked examples.

Standard libraries are imported by name (import math); vendor modules are bundled and imported with their path (import vendor/csv).

Standard Library

core

Lists, folds, higher-order helpers and type conversions - the functional toolbox.

import core

math

Constants, powers, roots, logs and trigonometry inspired by C's math.h.

import math

strings

Slice, split, join, case-convert and search text.

import strings

random

Random integers, doubles, choices and strings via the system C library.

import random

assert

Tiny assertion helpers for writing tests in Bern.

import assert

path

Join, normalize and inspect filesystem paths.

import path

url

Percent-encoding, query strings and full URL parsing/building.

import url

crypto

Tokens, checksums and UUID-like identifiers in pure Bern.

import crypto

json

Parse JSON into Bern values and serialize them back.

import json

Vendor Modules

vendor/csv

Read and write CSV data from strings or files.

import vendor/csv

vendor/http

A small FFI-backed HTTP server for static routes.

import vendor/http/http

vendor/bernparsec

A megaparsec-style parser-combinator library for building grammars.

import vendor/bernparsec

vendor/raylib

Bindings for raylib 5.5 - windowing, 2D/3D drawing, input and audio via FFI.

import vendor/raylib/raylib
