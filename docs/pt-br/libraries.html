Bibliotecas Bern

Toda biblioteca já vem com o Bern. Cada uma tem sua própria página, com referência completa das funções e exemplos práticos.

As bibliotecas padrão são importadas pelo nome (import math); os módulos vendor vêm embutidos e são importados pelo caminho (import vendor/csv).

Biblioteca Padrão

core

Listas, folds, funções de ordem superior e conversões de tipo - a caixa de ferramentas funcional.

import core

math

Constantes, potências, raízes, logaritmos e trigonometria inspirados no math.h do C.

import math

strings

Fatiar, dividir, juntar, converter caixa e buscar em textos.

import strings

random

Inteiros, doubles, escolhas e strings aleatórias via biblioteca C do sistema.

import random

assert

Pequenos auxiliares de asserção para escrever testes em Bern.

import assert

path

Juntar, normalizar e inspecionar caminhos do sistema de arquivos.

import path

url

Codificação percent, query strings e parsing/construção completa de URLs.

import url

crypto

Tokens, checksums e identificadores estilo UUID em Bern puro.

import crypto

json

Faz parse de JSON para valores Bern e serializa de volta.

import json

monads

Maybe, Either e uma lista encadeada, com maps, binds, operadores e travessias.

import monads

Módulos Vendor

vendor/csv

Ler e escrever dados CSV a partir de strings ou arquivos.

import vendor/csv

vendor/http

Um pequeno servidor HTTP via FFI para rotas estáticas.

import vendor/http/http

vendor/bernparsec

Uma biblioteca de combinadores de parser estilo megaparsec para construir gramáticas.

import vendor/bernparsec

vendor/raylib

Bindings para a raylib 5.5 - janelas, desenho 2D/3D, entrada e áudio via FFI.

import vendor/raylib/raylib
